    Layout

    Card look
    How each mail is drawn in cards view. "Theme" keeps what Thunderbird or your theme draws, for example flat rows.

    Unread and read mail

    How unread mail stands out in cards view, and how far read mail fades back.

    Outlook-style unread mail
    Blue bar and blue subject for unread mail, no read dot. Applies to cards view.
    Bar width

    Click the bar of a mail to mark it read or unread; on read mail the bar appears while you hover the left edge.

    Read mail

    How strongly read mail fades back. Unread mail is not affected.

    Dates and groups

    Date groups like "Today" and "Last 7 Days", and the Date column of the table view.

    Date in table view
    How the Date column shows when a mail arrived. Hover a date for the full date and time.
    Compact group headers
    When a folder is grouped (View → Sort by → Grouped by Sort), each group header takes one slim line in cards view instead of a whole card.
    Expand groups
    Groups like "Today" or "Last 7 Days" open expanded in every folder. Groups you collapse stay collapsed in that folder.
    All folders
    Group every folder of every account by date, newest first, or switch them all back to conversations. New folders follow. Single folders can still be changed in View → Sort by.

    Sender icons

    A logo for each sender your provider verified, initials for everyone else.

    Show sender icons

    In the message list and next to the sender in the reading pane.

    Verification per account

    Your provider stamps every mail it checked. Detect reads that stamp from your recent mail. Only mail with a positive stamp gets a logo; fakes get initials with a red !.

    Advanced
    Brand logos (BIMI)
    Official logos of big brands. The logo is downloaded from the brand's server, which can see your IP address.
    DNS resolver for BIMI
    Extra free-mail domains
    Senders from these domains always get initials (gmail.com, gmx.de and others are built in).
    Icons come from DuckDuckGo, which learns which domains mail you, not who. Senders' servers are never contacted.

    Reading

    Opening mail, the folder pane, and the remote content notice.

    Reading and folders

    Thunderbird's own settings, changed right here.

    Mark as read when shown
    Mail turns read as soon as it appears in the reading pane. Same as Settings → Reading & Display in Thunderbird, where you can also set a delay.
    Unified folders on top
    Inbox, Drafts, Sent, Spam and the other special folders of all accounts together, above the accounts. Thunderbird's own Unified Folders view (⋯ in the folder pane).

    The "remote content blocked" notice above a message.

    Compose

    The window for writing mail.

    Compose ribbon

    How the window for writing mail looks.

    Outlook-style compose ribbon
    Tabs with the formatting tools above the mail, instead of Thunderbird's compose toolbar and formatting bar.
    Style set for new mails
    New mails, replies and forwards start with it; drafts keep their own. In the ribbon: Style set → Set as default.

    Search

    The search field above the message list.

    Search field

    Words and keywords like from: or is:unread, with a filter panel.

    Officebird search instead of Thunderbird's search bar
    A query field with a filter panel. Turn it off to get Thunderbird's own search bar back.
    Default scope
    Where a search looks first; you can change it for each search.

    Calendar

    Thunderbird's Today Pane next to the mail (View → Today Pane).

    Today Pane

    The calendar column with the mini calendar and the coming events.

    Show the Today Pane next to mail
    The same as View → Today Pane (F11) in the mail tab.
    Officebird look for the Today Pane
    A mini calendar with today highlighted and the events in a card with a day column. Turn it off to get Thunderbird's own look back.
    Today's highlight
    Accent follows Thunderbird's accent (Settings → Appearance) or your theme.
    Custom highlight color
    Week numbers
    In the mini calendar of the Today Pane and the Calendar tab.
    Days in the agenda
    How many days the list shows when the Today Pane is on today.
